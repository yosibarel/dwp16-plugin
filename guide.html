Installation & first launch

DWP16 2 is available as a plug-in and a Standalone application. Download the installer for your system from the downloads page. Close your DAW before installing.

macOS

The universal installer includes VST3, Audio Unit, AAX and Standalone for Intel and Apple Silicon. Run DWP16Installer.pkg, then open your DAW and rescan plug-ins if necessary.

  • VST3: /Library/Audio/Plug-Ins/VST3/DWP16.vst3
  • Audio Unit: /Library/Audio/Plug-Ins/Components/DWP16.component
  • AAX: /Library/Application Support/Avid/Audio/Plug-Ins/DWP16.aaxplugin
  • Standalone: /Applications/DWP16.app

Windows

Extract DWP16-2.0.0-Windows.zip and run DWP16_Setup.exe. The installer includes VST3, AAX and Standalone. Open the Standalone application from the Start menu, or load the appropriate format in your compatible 64-bit DAW.

Factory presets and activation

The factory library imports automatically when required. Let the progress finish before choosing a factory preset. User presets are preserved when a newer factory package is imported.

Choose Activate from the main menu or open Settings → About & License and enter your license key. Without a license, DWP16 runs in trial mode. License validation requires a periodic internet connection.

First sound

  1. Choose a factory preset, or load a sample into a channel.
  2. Select Channel in the MIDI mode combo at the top left.
  3. Play a MIDI note or press a channel pad.
  4. Use Play for the player, Edit for the sample editor, Seq for sequencing, Glitch for glitch performance and FX for effects.

Channel pads & XY performance

Each of the 16 channels has its own XY pad. Press a pad to trigger its channel, then move within the pad to change that channel’s X and Y values. Drag between pads without releasing to move your performance between channels.

Pad display and playback

The display combo below the matrix offers Names, Linked XY, All XY and Blank. All XY shows a position dot on every channel pad. The X/Y assignment controls map movement to player pitch or gain; the same pad values are also available as modulation sources.

Pad-Q sets the musical timing for a channel’s pad trigger. With One shot off, holding the pad repeats its trigger at this interval; with One shot on, it triggers once on the grid. The player’s Loop control separately determines whether the sample itself loops.

Per-channel pad playback settings let you keep XY movement while choosing whether a pad also triggers audio when a sequencer is active.

Return positions and smoothing

Open Settings → XY, or right-click a pad and choose Pad XY Settings…. Choose one channel or All Channels, then set the default X/Y positions, return behavior and smoothing time in milliseconds.

  • Keep position: leave XY where you released it.
  • Return on release: return when you release the mouse.
  • Return on leave or release: return when you leave the pad or release the mouse.

Pitch/gain assignments follow these same smoothed XY values. The return settings are stored in presets. The lock beside the section heading protects them from preset replacement; project recall restores their state and locks.

The four additional XY controllers

The four numbered XY controllers in the master area are separate from the 16 channel pads. Each supplies an X and Y modulation source. Configure their return positions, behavior and smoothing in the Controls section of the same XY settings tab.

Pad context menu

Right-click a channel pad for sample loading, Rename, Pad XY Settings, Copy Channel, Paste Channel and Swap with channel. File-location and Process Sample commands appear when a sample is available. When renaming, press Tab to move to the next channel.

Player & channel controls

Select a channel at the top and open Play. Use the waveform and range handles to set the playback region. Loop repeats that region, and Rev reverses playback.

  • Atk / Rel: attack and release times.
  • Gain: channel level, displayed in dB.
  • Pan: stereo placement.
  • Pitch: sample transposition. Cont. Pitch enables continuous pitch instead of semitone steps.
  • Porta: glide between pitches.
  • Fade: the sample player’s boundary fade.
  • FM — Type, Wave, Freq and Depth: choose the FM behavior and waveform, then set frequency and modulation depth.

The Channel controls also provide Polyphony, Pitch bend range, Retrigger and the pitch algorithm. Hover a control to read its current information in the Info area.

Editing multiple channels

Hold Shift while changing supported player controls to apply the change across channels. Channel locks can protect channels from these group edits according to the option in Settings. A yellow outline indicates a group edit.

Channel presets, copy and swap

The player preset bar saves and loads a channel. Loading or pasting can show a section filter so you can choose which parts to replace. Copy/Paste Channel also works between DWP16 instances in the same application. Swap exchanges two channels; the dialog controls whether names and locked content are included.

Loading samples

Drop an audio file onto the waveform or a channel pad, or right-click the pad and choose Load audio file. Dropping several files on the pad matrix distributes them to channels starting at the drop position.

Use Open File Location to reveal the current sample in Finder or Explorer. This command is hidden when no sample is loaded.

Missing or unreadable samples

If a referenced sample cannot be loaded, the recovery panel lists the affected channel and reason. Locate a replacement, retry loading, or continue with the available audio. A file extension alone does not guarantee that the audio data inside is a supported format.

Sample Editor (Edit)

Select a channel and open the Edit tab. The expanded waveform provides sample-range editing and drawn modulation curves.

Sample Controls

Expand Sample Controls to choose Pitch LFO, Gain LFO or Position. Pitch LFO and Gain LFO are curves drawn over the sample, distinct from the three free-running LFO sources. Each has its own Reset button.

  • Time / Bars: choose the ruler’s display units.
  • Quantize: snap curve edits and loop boundaries. Off allows free editing; Grid follows the visible ruler; fixed musical divisions follow tempo.
  • From Loop Start: anchor fixed divisions to the selected loop start.
  • Position by Note: enable note-based position control.

Drag curve points to shape movement. Use the curve editor’s selection and context controls for editing a region. The range handles below the waveform set the sample’s playback start and end; zoom changes the visible window rather than those playback boundaries.

Editor menu

The editor menu contains Open File Location, Process sample, Import line and Save line. File-location and processing commands require a loaded sample. Import line and Save line load or save the editable curve.

Process Sample

Render the sample with the supported player processing, including reverse playback. Set Repeats and the reset-player option before starting. Progress is shown inside the same panel; controls that cannot be changed during processing are disabled. Use Cancel to request cancellation. With the reset option enabled, player controls are reset after the rendered sample is loaded.

MIDI input modes

The combo at the top left chooses the global MIDI routing mode:

  • Drum Map: notes address channels in a repeating 16-note map, offset by Center. The note determines the routed channel and pitch.
  • Channel: incoming notes play the selected channel.
  • Touch Pad: incoming notes provide pitch and velocity for pad performance. Select and trigger the sound with the pads.
  • Active Seq: route notes to channels whose sequencers have Play or Record enabled.

Center sets the note reference. Vel controls velocity influence. M-ptc is the global pitch offset. In Standalone, Z / X change Center by octaves within its supported range; this shortcut is not used by the plug-in.

Sequencer

Every channel and the Master have a sequencer with eight patterns, each containing up to 32 steps. The numbered buttons across the top select patterns; the grid edits the steps inside the displayed pattern. These are two different levels.

Lanes

  • Pitch / Vel / Len / Pan: note offset, velocity, gate length and stereo position per step.
  • Rate: timing division for each step.
  • Crv1 / Crv2: two sequencer modulation sources.
  • Snap: effect snapshot selection.
  • Ch: the channel to trigger in Master Channel Jumper mode.

Selecting patterns

Left-click a pattern number to display it and change its playback selection according to the mode below. Right-click displays it for editing without changing playback or playlist order. In Playlist mode, Shift-left-click removes the last occurrence of that pattern.

All seven pattern playback modes

  1. Selected: play one pattern. Selecting another switches at the next step without restarting the entire sequence.
  2. Sequence: enable the patterns you want and play them in ascending pattern-number order. Each runs for one complete cycle before the next begins. The sequence repeats.
  3. Playlist: clicking pattern numbers appends them in click order, including repeated entries, up to 16 entries. For example, 1, 1, 3, 2 plays pattern 1 twice, then 3, then 2, and repeats that order. Shift-left-click removes the last matching entry.
  4. Random: choose one enabled pattern at each cycle boundary. The same pattern may be selected again immediately.
  5. Shuffle: play every enabled pattern once in a shuffled order before starting another shuffled pass.
  6. Ping-pong: move through enabled patterns in ascending order, then return through them in descending order.
  7. Parallel: run all enabled patterns together. Their initial start is synchronized. A pattern enabled while playback is running joins at the running reference pattern’s next cycle boundary. Click an enabled pattern again to disable it; you can disable every pattern so none are playing.

Parallel values, Follow and FX Leader

Each parallel pattern uses its own step pitch, velocity, pan, length and timing. In Master Channel Jumper, each pattern also keeps its own channel/voice values. FX Leader chooses the pattern that supplies the shared sequencer curves and snapshot lane; it does not replace the independent note values of other parallel patterns.

Follow makes the editor follow the currently playing pattern in the modes that play one pattern at a time. It is not used in Parallel, where several patterns are running. Selection, playing progress, pending changes and the viewed pattern have distinct visual indicators.

Pattern cycles versus step direction

The Direct control changes the order of steps inside a pattern. It is independent of the PATTERNS playback mode. A forward or reverse cycle traverses the enabled step range. Random step direction counts one range-length of step choices before the next pattern; it does not wait until every step has been visited. Back-and-forth directions complete their outward and return pass, with endpoint repetition depending on the chosen direction.

Per-step Rate changes the time between steps. Parallel patterns can therefore have different cycle lengths; they share their launch timing but are not forced to finish every cycle together.

Timing and launch

Sync uses musical step divisions; with Sync off, timing is in milliseconds. Beat sets the base timing, Step sets the active step range and Direct selects its direction.

  • Now: start immediately when the sequencer is enabled and a note is available.
  • Beat: wait for the next quarter-note boundary.
  • Bar / 2 Bar / 4 Bar: wait for the next corresponding musical boundary, rather than counting that duration from the click.
  • Host: in plug-in mode, use the DAW transport and musical position for launch. Wait while the DAW is stopped. Host is absent in Standalone.
  • Q Retrig: when Retrig is on, quantize new-note restarts to the selected launch boundary. With Q Retrig off, a new-note restart is immediate.

The Play triangle indicates a pending start or retrigger in yellow. Releasing the relevant note while a start is pending cancels it. With Retrig off, stopping and starting resumes the retained next step and pattern order; with Retrig on, a new run restarts. Launch timing determines when a resume occurs.

Impose runs the sequencer without requiring a note trigger. The MIDI play-mode combo separately controls held, toggle and latch note behavior; it does not select the order of patterns.

Editing groups of steps

Hold Ctrl / Cmd when pressing the mouse in the grid, then drag to select steps. The gesture remains a selection until mouse-up, even if you release the modifier, so it does not accidentally edit values. Right-click for Copy Steps, Paste, Duplicate Steps and clearing the selection.

Copy/paste includes all step lanes. You can paste into another pattern or another channel. Ctrl/Cmd+C copies, Ctrl/Cmd+V pastes and Ctrl/Cmd+D duplicates after the selection. Operations stop at step 32: they do not wrap or spill into another pattern. Existing destination content requires overwrite confirmation. Esc clears the selection; loading a preset clears it too.

Recording and Master Channel Jumper

Enable Record and play MIDI notes to enter pitch, velocity and triggers in successive steps. Notes outside −24…+24 semitones move by whole octaves into the range, preserving their pitch class instead of clipping them all to the same boundary.

The Master also records pad input and Touch Pad performance. With Ch jumper enabled, recording includes the destination in the Ch lane: Drum Map uses the mapped channel, Channel uses the selected routed channel, and pad input uses the pressed pad’s channel. The pads show red recording states while Master Jumper recording is enabled. Toggling Jumper during recording preserves the recording cursor; with it off, recording no longer replaces the Ch lane.

All channels and locks

All channels links supported sequencer controls across channels 1–16, excluding Master. Supported Shift edits also apply across unlocked channels. A brief yellow outline confirms group changes. Sequencer locks protect pattern editing, recording and preset replacement.

Glitch & FX Only

Each channel and the Master have a Glitch section with four variations and their own settings. Use the performance buttons to choose variations; Playing marks the active one and Pending shows a queued change.

Two operating modes

  • Glitch: process captured audio. Beat and Len determine the captured region and playback length, while pitch, reverse and the other controls reshape its playback.
  • FX Only: keep the live audio running and use the variation timing to switch effect snapshots. Captured-audio controls, including waveform offset dragging, are disabled where they do not apply.

For snapshot changes from Glitch or FX Only, turn Auto off in the plug-in effects section, or Edit off in Standalone. Locked effect snapshots are protected according to the lock preference.

Controls for each variation

  • Weight: relative weight used when choosing between variations.
  • Beat: captured beat region/timing division.
  • Len: playback length.
  • Pitch / Porta: transposition and pitch transition.
  • Reverse / Pan / Gain: playback direction, stereo placement and level.
  • FX: the effect snapshot selected by this variation.
  • Snap: align glitch playback to Beat timing.
  • Rnd pitch / Rnd beat: randomize pitch or choose a random captured Beat region.

Hold Shift on supported variation controls to change all four on the current track; Alt+Shift resets them to their own defaults.

Mix, Mix Pan and Fade

  • Mix: wet/dry balance between glitch and the original signal.
  • Mix Pan: balance the glitch Mix between left and right, placing the dry signal on the opposite side. This is separate from a variation’s Pan.
  • Fade: smooth glitch entry, exit and loop boundaries over 0–100 ms.

Waveform, routing and triggering

In Glitch mode, drag the waveform horizontally to change the read offset. Alt-click resets it; Ctrl held at drag start uses a faster adjustment. Offset changes apply at the cycle boundary. Post FX places Glitch after the effect chain instead of before it. Retrigger restarts Glitch from MIDI notes. Glitch and FX Only require a tempo of at least 40 BPM.

Glitch has its own preset bar, copy/paste controls and preset lock. Copy can be pasted into another DWP16 instance in the same application.

Effects & snapshots

Each channel has an effect chain, and Master has a separate chain for the mixed output. Use the + control to choose an effect. Each effect panel provides its own controls, enable switch and lock.

Where to find snapshots

Open FX. The 1–8 buttons in the effects toolbar, beside Auto (Edit in Standalone), select the eight snapshots for the current channel’s effect chain. Master has its own chain and snapshots. These are effect-setting variations, separate from the sequencer’s eight patterns.

Creating and saving variations

  1. Enable Auto in the plug-in, or Edit in Standalone.
  2. Select a snapshot number and adjust the effect controls. Select another number to edit a different variation.
  3. Use Save or Save As in the FX preset bar to save the chain with all eight snapshots.

Snapshots are stored inside the effect-chain preset, not as separate files. Full and channel presets also include their effect-chain snapshot data. Snapshot data includes effect parameter values, On/Off, Sync, Link and supported step patterns. The selected snapshot and Auto/Edit mode are saved too. The effect types and chain order are shared across the eight snapshots.

The effect’s copy-to-all button copies its current snapshot settings to all eight snapshots. Randomise and Reset affect the current snapshot; hold Shift to apply their snapshot operations to all eight, respecting effect locks.

Auto in the plug-in

  • Auto on: select snapshots manually or through the host’s snapshot-selection automation parameter. Sequencer and Glitch snapshot requests do not take over the selection. Yellow indicators identify this state.
  • Auto off: allow the sequencer or Glitch engine to select snapshots. Incoming host snapshot automation is ignored while Auto is off. The sequencer’s Snap lane chooses an effect snapshot per step; each Glitch variation uses its FX value (1–8, or Rnd for a random choice). When Glitch supplies a snapshot, it takes priority over the sequencer.

Auto itself is a saved mode, not a host automation parameter. In Standalone the same button is labeled Edit, since there is no host snapshot automation. Yellow snapshot and effect indicators also apply there.

Locked effects

By default, locking an effect also protects its snapshot state: its current effect values stay in place when snapshots change, including changes requested by automation, the sequencer, Glitch or manual selection. You can still edit the locked effect’s controls; the lock keeps that effect on its pinned snapshot while other effects can follow the chain’s selection. Settings → Presets controls whether effect locking also locks snapshots. The default is enabled. This individual effect lock is distinct from the whole-chain preset lock.

Effect-chain presets and modulation

The FX preset bar saves or recalls chains. The chain’s preset lock protects it from full and channel preset loads. Copy/paste transfers the chain with its snapshots and settings. Assign LFOs, curves, MIDI or XY sources to supported parameters, or automate them from the DAW.

Presets & project recall

The main preset stores the instrument. Separate preset bars handle a channel, an effect chain, a sequencer and Glitch. LFO curves have their own Import line and Save line commands.

Save, Save As and read-only presets

Save updates the current editable preset; Save As writes a new copy. Use Save As to keep changes to a read-only factory preset. Brief Saving/Saved feedback is shown in the preset name area.

Load versus import

Load Preset opens an installed preset. Import Presets installs a packaged library and its audio. Export Preset packages the current preset and referenced samples; Export All Presets packages the library. Import/export show progress and completion feedback.

Copy, paste and swap

Channel Copy and Paste use a section/modulation filter when enabled. Copy/paste for channels, sequencers, Glitch and effects can transfer between DWP16 instances in the same application. Swap with channel exchanges channel content, with options for names and locked content.

Locks and projects

Locks protect their sections from preset replacement; they do not prevent a saved DAW project from restoring its own complete state. Loading a DAW project restores the saved instrument instead of applying the startup preset. Save your DAW project to retain its instance state even when the displayed factory preset is read-only.

Display preferences are stored separately from presets. In plug-in mode, loading a preset with internal tempo can temporarily reveal BPM controls without changing the saved display preference.

Modulation & XY sources

Use LFO 1, LFO 2, LFO 3, LFO 1+2, sequencer curves, MIDI sources and XY values to move supported controls. Pad X and Pad Y belong to each individual channel; the master’s four additional XY controllers provide X1/Y1 through X4/Y4.

Assign directly

Select a modulation source, then use the target knob’s modulation amount handle to set its depth. The source chain menu lists its connected targets; right-clicking a linked target knob lists its sources. Positive, Negative and Bipolar set the direction around the base value.

Modulation settings tab

Open Settings → Modulation for a searchable overview. Filter by channel or search a source/target name. Each row lists the source, target, depth and direction.

  1. Choose + Add Mapping.
  2. Select a source and a target, including their channel scope.
  3. Set Depth and Direction, then choose Add.
  4. Select an existing row to edit its source, target, depth or direction; Apply commits the edit and Cancel discards the draft.
  5. Use Remove for the selected mapping, or Undo/Redo to revisit edits.

Across channels

A source on one channel can control a parameter on another. For example, Ch 1 LFO 1 can move Ch 2’s filter frequency. A channel LFO continues to update even when its sample is not playing. If that LFO has Retrig enabled, it restarts from triggers on its source channel, not from the destination channel.

Reading the indicators

Linked knobs have a soft yellow connection indication when not in assignment mode. During assignment, the active source and range use the accent color. The moving marker represents the parameter’s modulated position; it is separate from the amount handle. Unlink from the source/target menus or remove the mapping in Settings.

Recorder

Use the recorder icon in the top bar or Settings → Display to show the bottom recorder panel. The recorder and on-screen keyboard have separate visibility controls.

Choose a source

Record the instrument’s output internally. In a compatible DAW, Sidechain captures the routed sidechain input; in Standalone, an external source uses your selected audio input and may require microphone permission.

Record and reuse

  1. Choose the source and check the input meters.
  2. Press Record and perform, or enable Auto and set the Threshold for level-triggered capture where applicable.
  3. Stop recording and audition the waveform.
  4. Use Export to save the take, or drag the recorded audio into a channel for further sampling.

The source selector, Refresh, input monitor, playback controls and export command are all inside the recorder panel. Recordings use the active audio sample rate.

Main menu & Settings

The menu button in the top bar opens the following sections. The names below match the version 2 menu.

Presets

  • Load Preset — choose an installed main preset.
  • Init Preset — load the empty preset.
  • Import Presets — install packaged presets.
  • Export Preset — export the current preset with its audio.
  • Export All Presets — export the library.

Preset Folders

Main Presets, Channel Presets, Effects Presets, Glitch Presets, Sequencer Presets and LFO Curves open their corresponding folders in Finder or Explorer.

Preferences

Settings opens the settings panel. Use the Display tab to configure interface visibility.

About & License

Activate appears in trial mode; an activated copy shows the disabled Activated item. About opens product information, and Check for Updates checks for a newer version.

Settings tabs

  • Display: interface visibility and display preferences, including Info, recorder, keyboard and BPM.
  • Files: file-related preferences.
  • About & License: activation, product information and Email My License.
  • Presets: preset handling and lock preferences, including effect snapshot protection and channel protection during Shift edits.
  • XY: channel-pad and additional-controller return behavior, default positions, smoothing and preset locks.
  • Updates: manual/automatic update checks, download details, reminders and skipped versions.
  • Modulation: view, filter, add, edit and remove mappings.

Clicking the Info area opens Display settings and briefly highlights its controls. Update availability is indicated near the settings gear. Automatic checks run in the background; when an update is waiting, checks become weekly.

Advanced menu

With Control held when opening the menu, an Advanced section also exposes Show Log Folder, Show Log File and Save as Init Preset.
