Before you start

A few useful details.

Do I need Ableton Live to use Rift?

Only for the shared multi-track workflow, which requires Ableton Live with Max for Live. You can also load Rift directly as a single-track VST3, AU or AAX plug-in in a compatible host.

Where does the Max for Live device go?

The macOS installer places the self-contained Rift.amxd device in the default Ableton User Library under Presets → Audio Effects → Max Audio Effect → Rift. A copy is also installed in /Library/Application Support/DWP Rift/MaxForLive. If you use a custom User Library, copy Rift.amxd into it.

Can I use my presets in both workflows?

Yes. Track, Controls and Effects presets use the same formats. A track preset contains its settings rather than relying on separate effect or control preset files.

Do I need the Android app?

No. Rift Remote is an optional controller for the Max for Live workflow. You can perform directly in the plug-in without a phone.
